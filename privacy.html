jbot Privacy Policy

Effective October 8, 2026

Who uses jbot

jbot is a personal, self-hosted assistant used only by its owner. It is not offered to the public.

What data jbot accesses

jbot accesses Google Calendar data (through the calendar.events permission) only to show and create calendar events that the owner asks for.

Where data is stored

Data stays on the owner's own computer. The Google sign-in token is stored locally on that computer and is not uploaded anywhere else.

Sharing

jbot does not sell, share, or transfer Google user data to anyone. It does not use Google user data for advertising or to train AI models.

Google API Services User Data Policy

jbot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke jbot's access to their Google account at any time at https://myaccount.google.com/permissions.
